# Pillar: Strategic Minerals

`twg_pillar` values that map here: "Strategic Minerals", "Minerals", "Critical
Minerals", "Mining".

**Resonance layer.** Posts must read as the WAIIS *strategic minerals* agenda —
value addition and beneficiation *in Africa*, not raw extraction/export copy.

## What the pillar is about
Moving West Africa up the minerals value chain: local beneficiation and
downstream processing, responsible and traceable sourcing, and bankable
mineral-linked industrial projects — so more value stays on the continent.

## Framing that resonates
- Value addition and beneficiation — processing, not just extraction.
- Downstream industrialisation and regional mineral value chains.
- Responsible, traceable, well-governed sourcing (ESG credibility).
- Bankable, investment-ready projects through the WAIIS platform + deal room.
- Minerals as an input to the wider industrial and energy transition.

## Lexicon
**Use:** value addition, beneficiation, downstream processing, mineral value
chains, responsible/traceable sourcing, resource governance, industrialisation,
bankable pipeline, project preparation.
**Avoid / handle with care:** specific reserves/tonnage/valuation figures, named
concessions or licences, "secured"/"awarded" language — unless public.

## Pillar guardrails (on top of house rules)
- No reserve sizes, valuations, or investment figures unless in the public summary.
- Never imply a concession, licence, or offtake is awarded or signed.
- Emphasise governance/responsibility; avoid extractive-boom framing.
- Name only cleared companies/countries.
